# OpenFAST Input Files
We provide MoorDyn files for the mooring system and dynamic power cable here. 
The mooring system polyester dynamic stiffness is calculated based on the offset position in each load case, 
so a different moordyn file is provided for the main ULS cases and directions. 

The dynamic power cable designs are for three conductor sizes (300, 630, and 1000 mm^2) and include both lazy wave and suspended designs.

For the platform and wind turbine, we used the IEA 15 MW reference wind turbine and the UMaine VolturnUS-S semi-submersible. 
The other OpenFAST input files are available here: https://github.com/IEAWindSystems/IEA-15-240-RWT/tree/master/OpenFAST/IEA-15-240-RWT-UMaineSemi
